One image summing up the world's news of **Tuesday 17 November 2026** — a dense newspaper front page with 32 stories across six continents, led by the U.S.–Iran strikes in the Strait of Hormuz, the Kerch Bridge collapse, Nvidia's $115.8B quarter, and the Quad summit in Manila.

Built for the [make.fun](https://make.fun/c/news-image-20261117) competition "Sum up 17 November's world news in one image" (news-image-20261117).

## How it works

`main.ts` copies `entry.png` to `$MAKEFUN_OUTPUT_DIR/entry.png`. The image is drawn from `image-source.html` (rendered once to PNG with headless Chrome); the program itself makes no network or model calls and is fully deterministic — every run writes the same bytes.
